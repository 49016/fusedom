How to Use FuseDOM

FuseDOM allows you to manipulate this web page's DOM using filesystem operations!

Setup:

  1. Run the server: npm install && node server.js ./mnt 8080
  2. Open this page in your browser
  3. Use filesystem commands to modify the DOM

Example Commands:

Try these commands in your terminal (in a new terminal window, not where the server is running):

# List the DOM structure
ls -la ./mnt/

# View current body content
cat ./mnt/0.html/0.body/innerHTML

# Change the demo content
echo "<h2>Hello from the filesystem!</h2><p>This was written via echo command</p>" > ./mnt/0.html/0.body/innerHTML

# Or modify specific elements
echo "Modified via FUSE" > ./mnt/0.html/0.body/0.div/innerHTML

# Change text content
echo "New Title" > ./mnt/0.html/0.body/0.div/0.h1/innerText

Structure:

The filesystem represents the DOM as:

  • 0.html - The root HTML element (index 0)
  • 0.body - The body element (first body child of html)
  • innerHTML, innerText, textContent - Properties you can read/write
